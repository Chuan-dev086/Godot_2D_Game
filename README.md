# 🔫 Top-Down Survival Shooter (Godot & C#)

A minimalist top-down 2D action game built with **Godot 4** and **C#**. 

This project is a journey into game development, transitioning from web/app development to creating interactive game mechanics, physics, and enemy AI.

## 🎮 Gameplay

You control a character in a confined arena. Your goal is to survive and eliminate all enemies in the room. 
- Use **WASD** to move.
- Use **Mouse** to aim and **Left Click** to shoot.
- If you touch an enemy, you take damage. If you shoot an enemy, it dies.
- Clear all enemies to win the stage.

## ✨ Features (Roadmap)

- [x] **Phase 1: Basic Physics & Movement** - `CharacterBody2D` implementation with collision detection so the player cannot walk through walls.
- [ ] **Phase 2: Shooting Mechanics** - Spawn projectile `Area2D` bullets towards the mouse cursor.
- [ ] **Phase 3: Enemy AI** - Enemies that spawn and continuously chase the player.
- [ ] **Phase 4: Combat & Game Loop** - Health system, damage detection, score tracking, and a win/lose condition.

## 🛠️ Tech Stack

- **Engine:** Godot 4.x
- **Language:** C# (.NET)
- **Editor:** Visual Studio Code
